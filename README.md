# Sales-Performance-Analysis-Report
![My Dashboard](https://github.com/AdebiyiDeborah/Sales-Performance-Analysis-Report/blob/main/Sales%20Performance%20Dashboard.jpg)


### Introduction

This project explores how data-driven sales performance analysis can transform business strategy, boost revenue, and support smarter decision-making. By understanding key sales metrics, using dashboards to visualize performance, and applying actionable insights, businesses can optimize their sales processes effectively.

### Objectives and Goals
### Objectives

- Identify strengths, weaknesses, and opportunities in sales performance

- Improve overall sales effectiveness

- Drive revenue growth

### Goals

- Increase deals closed per sales representative

- Enhance sales forecasting accuracy

- Optimize sales strategies (e.g., focusing on high-margin products)

### Problem Statement

Every business aims to grow revenue and improve conversion rates.
This project focuses on analyzing:

- Revenue growth by region

- Performance by product

- Performance by salesperson

### Dataset and Methodology
Data Source

Sales Performance Dataset from Kaggle

Data Cleaning

Removal of duplicates

Ensured numeric consistency

General data quality checks

Analytical Tool

Microsoft Power BI

### Story of the Data

The dataset tells the story of goods sold by a firm operating across multiple countries. It captures:

- Customer details

- Products purchased

- Quantities sold

- Salespersons involved

- Revenue generated and such alike.

### Data Structure

- Each row represents a unique transaction

- Each column represents a unique data attribute

### Key Features and Significance

- Customer Name – Identifies buyers

- Salesperson – Tracks seller performance

- Product Name – Shows items sold

- Revenue – Sales value generated

- Order ID – Unique transaction identifier

### Data Splitting and Preprocessing
### Independent Variables

- Customer name

- Address, city, state, country/region

- Product name, category

- Payment type

### Dependent Variables

- Order ID

- Order date

- Customer ID

- Revenue

- Unit price

- Quantity

- Shipped date
